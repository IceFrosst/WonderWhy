# Meta Discord channel notes (copied verbatim, 13 Nov)

## Getting started
Please send your agents (or your own eyes) to https://wearables.developer.meta.com to learn about development.

If you want to get started on building webapps for Meta Ray Ban Display glasses, please take a look at our simulator: https://chromewebstore.google.com/detail/jpjlmmodokemlepklkdbimceggpbjcll

There are two frameworks to choose from.
- Device Access Toolkit: https://wearables.developer.meta.com/docs/develop/dat/getting-started-toolkit
- Web Apps: https://wearables.developer.meta.com/docs/develop/webapps
- UI toolkit: https://wearables.developer.meta.com/docs/develop/webapps/design/getting-started/what-is-the-toolkit/

Here are some github links to also send your agents also.
- https://github.com/meta/meta-wearables-webapp
- https://github.com/meta/meta-wearables-dat-ios
- https://github.com/meta/meta-wearables-dat-android

## Common issues when you check out the hardware
- Device is registered with another account? It needs to be factory reset.
  - Glasses: https://www.meta.com/en-gb/help/ai-glasses/814846737027479/
  - Meta Neural Band: https://www.meta.com/en-gb/help/ai-glasses/1481163499576351/
- Unable to pair the device?
  - Glasses: https://www.meta.com/en-gb/help/ai-glasses/852077233025627/
  - Meta Neural Band: https://www.meta.com/en-gb/help/ai-glasses/770840295349358/
